# ImageLibraryProject

## Description
Application C++ de gestion de bibliothèques d'images et de traitement d'images.

## Technologies
- C++
- OpenCV
- CMake
- Git et GitHub

## Organisation de l'équipe
Projet réalisé par une équipe de 6 étudiants.

## Fonctionnalités principales
- Gestion des bibliothèques d'images
- Gestion des utilisateurs et des droits d'accès
- Traitement d'images
- Interface graphique
- Sauvegarde et chargement des bibliothèques

## Structure
- include/: fichiers d'en-tête
- src/: code source
- data/: images et bibliothèques
- tests/: tests
- docs/: documentation
